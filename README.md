# J.E.S HOST

بنية أولية فعلية لمنصة إدارة مشاريع Node.js. الواجهة ثابتة، والـ API منفصل، وقاعدة البيانات PostgreSQL. **محرك تشغيل البوتات غير مربوط بمزوّد بعد**؛ لذلك لا تدّعي هذه النسخة أنها تشغّل عمليات Node.js حتى تتم إضافة مزوّد تشغيل حقيقي.

## الملفات
- ``: واجهة عربية RTL ثابتة.
- `backend/`: API Node.js مع إنشاء حساب الإدارة لأول مرة وتسجيل الدخول والجلسات.
- `schema.sql`: مخطط PostgreSQL.
- `engine/`: عقد تكامل محرك التشغيل.

## النشر
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. انشر `` عبر GitHub Pages أو Cloudflare Pages.
3. انشر `backend/` على خدمة تدعم Node.js وHTTPS، واضبط متغيرات البيئة من لوحة الخدمة.
4. أنشئ قاعدة PostgreSQL، ثم نفّذ `schema.sql` من لوحة SQL الخاصة بالمزوّد.
5. اضبط `FRONTEND_ORIGIN` على عنوان الواجهة و`DATABASE_URL` و`SESSION_SECRET` و`ADMIN_SETUP_KEY`.
6. في أول تشغيل، افتح الواجهة واستخدم إعداد الإدارة مع `ADMIN_SETUP_KEY`. بعد إنشاء الحساب، عطّل `ALLOW_ADMIN_SETUP` أو احذفه من متغيرات البيئة.

## متغيرات البيئة
انسخ `.env.example` إلى `.env` محليًا فقط عند الحاجة. لا ترفع `.env` إلى GitHub.

## الحدود الحالية
- تسجيل الدخول والجلسات والمشاريع الأساسية موصولة بالـ API.
- إنشاء المشروع ينشئ سجلًا فقط في هذه المرحلة؛ لا يكتمل كبيئة قابلة للتشغيل إلا بعد ربط مزوّد تشغيل/تخزين حقيقي في `engine/`.
- رفع الملفات وتشغيل npm install وتشغيل العمليات والسجلات الحية والنطاقات العامة غير مفعّلة في هذه النسخة؛ لن تُعرض على أنها تعمل.
- استخدم HTTPS في النشر العام. لا تستخدم هذا الإصدار على الإنترنت قبل مراجعة إعدادات الأمان وسياسات مزوّد التشغيل.


## ملاحظة عن بنية الملفات
جميع الملفات في جذر المستودع مباشرة. هذه نسخة تأسيسية؛ محرك تشغيل المشاريع الحقيقي يحتاج إلى مزود تشغيل خارجي ولم يُدمج بعد.
